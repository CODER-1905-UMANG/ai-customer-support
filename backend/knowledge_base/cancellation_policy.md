# Cancellation Policy

## Order Cancellation

Customers can request cancellation before an order enters the shipping
process.

## Before Shipping

If an order has not entered the shipping process, the cancellation
request can be processed by the support system after verifying the
order.

## After Shipping

Once an order has been shipped, cancellation may no longer be
available.

The customer may need to follow the applicable return or refund process
instead.

## Cancellation Request

Customers should provide their order number when requesting
cancellation.

The support system should check the current order status before
determining whether cancellation can proceed.

## Failed Orders

Orders that have failed may require additional investigation,
particularly when a payment has already been completed.

## Human Support

Customers can request human support if they disagree with the
cancellation decision or if the issue requires manual investigation.
