# Payment Policy

## Supported Payment Methods

TechNova supports the following payment methods:

- Credit cards
- Debit cards
- UPI
- Net banking
- Digital wallets

## Payment Confirmation

After a successful payment, the payment system records the transaction
and associates it with the customer's order.

Customers can provide their order number to request payment-status
information.

## Payment Failed

If a payment fails, customers should verify the payment status before
attempting the transaction again.

If money appears to have been deducted despite a failed order, support
should verify both the payment and order records.

## Payment Deducted but Order Failed

When a customer's payment is successful but the associated order has
failed, the support system should:

1. Check the order status.
2. Check the payment status.
3. Determine whether the issue can be resolved automatically.
4. Create a support ticket when necessary.
5. Escalate the issue to human support when manual investigation is
   required.

## Refunds for Payment Issues

If a refund is required, the applicable refund process should be
followed.

The time required for a refund to appear may depend on the payment
provider or bank.

## Payment Security

Customers should not share sensitive payment credentials such as
passwords, PINs, CVVs, or one-time passwords with support agents.

Support should only request information necessary to investigate the
payment issue.
